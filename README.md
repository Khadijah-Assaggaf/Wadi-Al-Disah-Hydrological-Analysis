# Hydrological Analysis (Wadi Al-Disah, Tabuk)

## Overview
A GIS study analyzing surface water flow and mapping the drainage basin for Wadi Al-Disah in Tabuk using DEM data[

## Workflow & Steps
- **Data Collection:** Downloaded DEM data from USGS Earth Explorer
- **Data Correction:** Processed DEM using the Fill tool in ArcGIS Pro
- **Flow Analysis:** Calculated Flow Direction and Flow Accumulation
- **Stream Network:** Extracted streams using the Con tool and classified Stream Orders
- **Watershed Delineation:** Mapped main watersheds and sub-basins based on pour points

## Tools Used
- ArcGIS Pro (Spatial Analyst)
- USGS Earth Explorer
  
## Deliverables & Results
- Drainage Basin & Sub-basin Maps
- Stream Network Classification Maps
