# Hydrological Analysis (Wadi Al-Disah, Tabuk)

## Overview
A GIS study analyzing surface water flow and mapping the drainage basin for Wadi Al-Disah in Tabuk using DEM data[span_0](start_span)[span_0](end_span).

## Workflow & Steps
- **Data Collection:** Downloaded DEM data from USGS Earth Explorer[span_1](start_span)[span_1](end_span).
- **Data Correction:** Processed DEM using the Fill tool in ArcGIS Pro[span_2](start_span)[span_2](end_span).
- **Flow Analysis:** Calculated Flow Direction and Flow Accumulation[span_3](start_span)[span_3](end_span).
- **Stream Network:** Extracted streams using the Con tool and classified Stream Orders[span_4](start_span)[span_4](end_span).
- **Watershed Delineation:** Mapped main watersheds and sub-basins based on pour points[span_5](start_span)[span_5](end_span).

## Tools Used
- ArcGIS Pro (Spatial Analyst)[span_6](start_span)[span_6](end_span)
- USGS Earth Explorer[span_7](start_span)[span_7](end_span)

## Deliverables & Results
- Drainage Basin & Sub-basin Maps[span_8](start_span)[span_8](end_span)
- Stream Network Classification Maps[span_9](start_span)[span_9](end_span)
